Behavior and limits:
Failed ffprobe still returns 0.0, preserving the pre-existing unknown-duration
fallback; this change does not tighten duration enforcement or alter timeout.
FFPROBE_DIAGNOSTIC_V1 contains only schema, stage and a fixed kind. No exception
text, command, stdout, stderr or path is copied. yt-dlp, network download errors
and unrelated application logging remain outside this privacy guarantee.
