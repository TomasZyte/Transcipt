# Telegram-бот транскрибации

Бот на aiogram 3. Принимает аудио/видео → шлёт на ваш RunPod-эндпоинт → возвращает
расшифровку с диаризацией, конспектом и кнопками-инструментами (протокол, задачи,
цифры, Q&A, перевод) + экспорт .srt/.txt/.md. Лимиты по тарифам и промокоды — в SQLite.

## Что в этой версии (ядро)
- Приём голосовых/аудио/видео/кружков/документов-медиа.
- Транскрибация + диаризация через RunPod (переиспользует рабочий эндпоинт).
- Инструменты по тексту (analyze на воркере, локальная LLM): краткое содержание,
  тезисы, протокол, задачи, цифры/даты/бюджет, вопрос к AI, перевод (7 языков).
- Экспорт .srt / .txt / .md.
- Тарифы (free/start/pro), лимиты по минутам, промокоды (в т.ч. Про 100% бессрочно).
- Глоссарий терминов на пользователя.

## Следующий слой (нужны ваши реквизиты)
- Приём ссылок YouTube/VK/RuTube (yt-dlp).
- Оплата (Telegram Stars или ЮKassa) — нужен провайдер/ключи.

## Запуск
1. Создайте бота в @BotFather → получите `BOT_TOKEN`.
2. Скопируйте `.env.example` → `.env`, заполните BOT_TOKEN, RUNPOD_*, S3_*, ADMINS.
   (RunPod ENDPOINT_ID и API key — из вашего эндпоинта; S3 — R2/B2/MinIO.)
3. Установите и запустите:
   ```bash
   pip install -r requirements.txt
   python bot.py
   ```
   Бот работает на long-polling — годится для дешёвого VPS 24/7 (GPU не нужен).

## Промокоды (для узкого круга — скидка 100%)
Вы (из списка ADMINS) в чате с ботом:
```
/newpromo VOINZ-ALFA pro 0 -1
```
- `pro` — тариф, `0` — месяцев (0 = бессрочно), `-1` — число активаций (-1 = безлимит).
Пользователь активирует: Настройки → «Ввести промокод», или `/promo VOINZ-ALFA`.

## Важно про воркер
Нужен обновлённый воркер с экшеном `analyze` (уже в репозитории transcribe-backend:
pipeline.py + handler.py). Если ещё не задеплоен — запушьте и дождитесь пересборки RunPod,
иначе кнопки-инструменты не будут работать (расшифровка при этом работает).

## Где хостить
- Бот: любой дешёвый VPS (1 vCPU / 1 ГБ) — процесс лёгкий.
- GPU-обработка: остаётся на RunPod serverless (scale-to-zero).
