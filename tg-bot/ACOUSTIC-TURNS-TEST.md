# Акустическая проверка коротких голосов

`acoustic-turns-v1` — только тестовый образ и endpoint. Готовность к
production не заявлена. Исходный WhisperX large-v3 распознаёт sound1–4
один раз; его текст, native timestamps и границы окон общие для всех
вариантов. Ручные слова, секунды, пол, возраст и число людей модели не
передаются.

Проверяется гипотеза: понижение высоты звука может помочь моделям
выравнивания/диаризации на высоких голосах. Это эксперимент, а не
доказанное улучшение. `librosa.effects.pitch_shift` 0.11.0, soxr_hq,
−3/−6 полутонов; число отсчётов, частота 16 kHz и длительность сохраняются.
Преобразование применяется ко всему файлу, а не к вручную выбранным
детским секундам. ASR работает только с исходным звуком.

Для каждого преобразования отдельно сравниваются изменённое выравнивание,
изменённая диаризация и оба вместе; с исходным контролем всего 7 вариантов.
Community-1 сохраняет min_active_ratio=.1 и прежние VBx-параметры.
Сохраняются хэши преобразованного PCM, локальные и глобальные временные
метки, исходные аннотации и воспроизводимый экспорт. Перенумерация спикеров
вручную и выбор «лучшего» варианта по эталону внутри воркера запрещены.

CPU CI проверяет длину, частоту, отсутствие большой задержки и правильное
направление pitch shift на синтетическом сигнале без внешней сети.
Клиент должен проверить историю расходов перед единственной попыткой.
Резерв $0.50 сохраняется; старые резервы можно закрыть только отдельным
неизменяемым документом сверки с учётом задержки биллинга. Более свежие
попытки, ещё не попавшие в биллинг, учитываются полным резервом.

Перед запуском: FULL_PIPELINE_TEST=1, ACOUSTIC_TURNS_TEST=1, остальные
экспериментальные флаги=0. Active=0, Max=1, GPU ≤$0.75/ч, idle=5 с,
timeout=300 с, FlashBoot off; процесс ограничен 270 с, повторов нет.
После терминального статуса Max и флаги вернуть в 0, проверить health.

Успех требует независимой оценки детских реплик, взрослых голосов и
sound1/3/4. Уверенность CTC не является вероятностью правильного времени.
Ручные границы второй реплики приблизительные; ранний crop начинался
с 14.5 с, поэтому миллисекундная точность эталона не подтверждена.

API преобразования: [librosa 0.11.0](https://librosa.org/doc/0.11.0/generated/librosa.effects.pitch_shift.html).
