# Проверка границ контекста WhisperX

`pause-context-v1` — изолированное сравнение на sound1–4. Рабочий бот,
production Dockerfile и main не меняются. Готовность качества не заявлена.

В предыдущем `timed-turns-v1` CTC получал интервалы отдельных предложений
по timestamp-декодеру. Последнее предложение sound2 завершалось на 15.76 с,
хотя акустическое окно продолжалось до 17.09 с. В таком режиме выравнивание
не могло найти слова за пределами предсказанного конца.

Три варианта используют один текст WhisperX large-v3 и исходный звук:

- `control`: прежние границы предложений, результат сохранён без пересчёта;
- `extend_tail`: конец последнего предложения расширен до конца окна;
- `joint_window`: весь упорядоченный текст окна выравнивается совместно,
  без временных ограничений отдельных предложений timestamp-декодера.

Окна определяются автоматически по акустическим паузам, максимум 15 секунд.
Текст не исправляется и не подсказывается модели. Повторяющиеся фразы в
`joint_window` не выравниваются независимо в перекрывающихся интервалах.
Локальные времена сохранены отдельно; смещение исходного окна добавляется
ровно один раз. Все шесть экспортов воспроизводятся из сохранённых данных.

Диаризация — прежняя Community-1 с min_active_ratio=.1, шагом .1 или .05.
Нет переназначения женской метки по эталону, сглаживания коротких реплик,
pitch shift, подсказки числа людей или пола/возраста. Сравнение проверяет,
поможет ли более точное выравнивание разделению слов по исходным голосам.
Если смешивание останется, это отдельная нерешённая ошибка диаризации.

Проверка владельца приблизительная: первая детская фраза около 11.5–12.5 с,
вторая около 14.5–17 с. Эти интервалы используются только в офлайн-приёмке;
модели их не получают. Технический успех не означает прохождение качества.
Sound3/4 проверяются на сохранение одного спикера; sound1 содержит пение.

## Ограничения запуска

Клиент `pause_context_test.py` по умолчанию проверяет подготовку без сети.
Одна явная `--submit` допускает одну задачу с четырьмя файлами и без повторов.
R2/RunPod ограничены `poslovnica-test` / `tt17em69to6yua`.

Новая кампания связывает SHA-256 всех 16 исторических журналов, предыдущей
кампании и остановки. Сохраняется весь предыдущий план $1.25; новая попытка
резервирует $0.50. Общий план **$1.75/$2**, без обнуления истории.
30.10 в 12:23 UTC наблюдались начисления $0.172 за 1–30 октября UTC.
Биллинг отстаёт на час и не заменяет сохранённые резервы. Перед POST
обязательны свежая таблица и preflight (не старше 15 минут), точный образ,
совпадение health со старой остановкой, отсутствие активных заданий.

Флаги `FULL_PIPELINE_TEST=1`, `PAUSE_CONTEXT_TEST=1`, остальные тестовые
флаги 0. Active=0, Max=1, один GPU ≤$0.75/ч, idle=5 с, timeout=300 с,
FlashBoot off, subprocess=270 с. После терминального результата вернуть
Max и флаги в 0 и проверить health. Новый образ сам по себе GPU не запускает.

API: [WhisperX 3.8.6 alignment](https://github.com/m-bain/whisperX/blob/v3.8.6/whisperx/alignment.py).
