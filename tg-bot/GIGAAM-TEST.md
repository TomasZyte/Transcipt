Кампания `gigaam-children-v1` выполнена **один раз и исчерпана**.

Это не подтверждённое преимущество новой модели над WhisperX.

executionTime=7,898 с, delayTime=8,736 с. Внутри процесса загрузка модели

## Изоляция и сборка

Только endpoint `tt17em69to6yua` и бакет `poslovnica-test`. Теперь тестовый
endpoint связан с **`codex/asr-build-check`**, Dockerfile
`transcribe-backend/worker/Dockerfile.asr-gigaam`, код `2bd8f040f`.
Push в эту ветку может запускать тестовую автосборку даже при Max=0.
Рабочий endpoint, R2 `transcribe`, VPS, основной бот и `main` не менялись.

Активная RunPod-сборка подтверждена Completed. Семь файлов образа совпали
с прошедшей CPU-проверку сборкой GitHub Actions `40847234871`.
Официальный GigaAM закреплён на ревизии
`7447938d791c4f3e643386ee22c33777004293a5`; checkpoint `v3_rnnt.ckpt`
вшит в образ и проверяется по lock. Torch/torchaudio 2.8.0, CUDA 12.8,
fp16 encoder, Flash Attention выключен. В процессе модели сеть блокируется.
Известные фразы владельца не подаются как подсказки.

После задания сохранены **Active/Max=0/0**, ASR_COMPARISON_TEST=0,
FULL_PIPELINE_TEST=0, CONTEXT_ASR_TEST=0. Release #26 подтверждает
выключение ASR. API `/health` подтвердил completed=11, inProgress/inQueue=0,
все workers=0; failed=1/retried=2 относятся к прежним тестам.

## Клиент и проверки

`gigaam_test.py` допускает только один фиксированный WAV и `gigaam_v3`.
Кампания закрепляет хеши всех прежних попыток, аудио/manifest, образ,
ревизию и бюджет. Общий process lock, запись до POST, отмена по таймауту,
запрет автоматического повтора наследуются от тестовых клиентов.

Preflight не старше 15 минут подтверждает только тестовый endpoint,
Active=0/Max=1, GPU count=1, idle=5 с, FlashBoot off, GPU ≤$0,75/ч,
execution timeout=120 с, ASR_COMPARISON_TEST=1, два остальных флага=0.
Request policy: execution=120 с / TTL=240 с; клиент=270 с.
Проверяются исходный текст, отсутствие выдуманных тайм-кодов, SHA аудио,
конфигурация, ревизия и runtime lock. Восемь новых и всего 99 офлайн-тестов
бота/клиентов прошли. Код образа и production-зависимости не менялись.

Без `--submit` клиент не обращается к сети. В уже использованном каталоге
он останавливается на защите от повтора, в том числе при офлайн-вызове:

```powershell
.\.venv\Scripts\python.exe tg-bot/gigaam_test.py --env-file .env.integration-test
```

Для следующего эксперимента нужны новая цель проверки, отдельная кампания,
сохранение истории и свежая сверка общего бюджета. Этот результат сам по
себе не разрешает новый платный запуск или перенос модели в production.
