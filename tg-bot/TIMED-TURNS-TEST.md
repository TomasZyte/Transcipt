## Устройство эксперимента

Профиль `timed-turns-v1`, только тестовый endpoint и R2. Production и
`main` не меняются. Предыдущие результаты/журналы не перезаписываются.

В release-candidate-v1 две детские фразы попали в один ASR-фрагмент;
CTC выравнивание начало вторую слишком рано и растянуло последнее слово.
В новом варианте сохраняются WhisperX 3.8.6 и large-v3, но используется
унаследованный timestamp-декодер уже загруженного `WhisperModel`, с
`word_timestamps=True`. Границы предложений определяются по пунктуации
самого ASR и его временным меткам. WhisperX затем выравнивает каждое
предложение внутри этих границ. Эталонные слова/секунды не передаются
модели. Исходные слова декодера, границы и результат CTC сохраняются;
клиент воспроизводит перенос времени и экспорт.

Это другой режим декодирования той же модели; он может изменить текст.
Его точность нельзя считать доказанной до сравнения. Для контроля
регрессии одна ограниченная задача обрабатывает sound1–4.

Диаризация сравнивает три акустических режима Community-1 при неизменных
VBx-параметрах и min_active_ratio=.1:

| Режим | Шаг окна анализа | Исключать перекрывающуюся речь из embeddings |
| --- | --- | --- |
| short | 10% длины окна | да |
| dense | 5% длины окна | да |
| overlap | 5% длины окна | нет |

Настройки временные, применяются только к экземпляру тестового pipeline
и восстанавливаются даже при исключении. Роли, число людей и ручная
перенумерация меток не используются. Все варианты получают один и тот
же ASR/alignment. Нельзя заранее объявлять какой-либо из них исправлением.

Источники реализации: [WhisperX 3.8.6](https://github.com/m-bain/whisperX/blob/v3.8.6/whisperx/asr.py),
[timestamp decoder faster-whisper 1.2.1](https://github.com/SYSTRAN/faster-whisper/blob/v1.2.1/faster_whisper/transcribe.py),
[Community-1 pipeline API 4.0.3](https://github.com/pyannote/pyannote-audio/blob/4.0.3/src/pyannote/audio/pipelines/speaker_diarization.py).

## Бюджет и запуск

Сохраняется предыдущий полный плановый расход $1.25, новая единственная
попытка резервирует $0.50: всего $1.75/$2. Перед POST сверяются UI-биллинг
за весь период, 14 неизменённых терминальных журналов и облачное состояние.
Старое показание биллинга не заменяет сохранённый резерв при задержке UI.
Кампания привязана к коммиту, хэшам моделей, аудио и предыдущей остановке.

Флаги FULL_PIPELINE_TEST=1, TIMED_TURNS_TEST=1, остальные экспериментальные
флаги 0. Active=0, Max=1, одна GPU ≤$0.75/ч, idle=5 с, timeout=300 с,
FlashBoot off. Подпроцесс 270 с, без автоматического повтора. После задачи
флаги и Max=0, затем проверить очередь и workers. Секреты и расшифровки
сохраняются только в игнорируемых локальных файлах.

Офлайн: `python tg-bot/timed_turn_test.py --env-file .env.integration-test`.
`--submit` — только при неизменяемой кампании и свежем preflight.

Критерии: обе детские фразы присутствуют, время соответствует независимой
разметке, их слова не назначены взрослым; неизвестный голос не считается
успешным разделением. Дополнительно проверяются голос отца и sound1/3/4.
Новые номера спикеров сначала сопоставляются с взрослыми по сохранённым
акустическим участкам, затем создаётся отдельный локальный отчёт.
